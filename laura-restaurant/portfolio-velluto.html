Project Overview

Velluto Ristorante needed to eliminate the manual overhead of managing table reservations. I designed and deployed a complete automation pipeline using n8n (self-hosted on EasyPanel) that connects the restaurant's React web form directly to their back-office tools — replacing spreadsheet copy-paste, one-by-one email writing, and manual call scheduling with a single, fully automated flow that processes each reservation in under 3 seconds.

Workflow — n8n Editor View
Fig. 1 — Live n8n workflow · 8 nodes · deployed on EasyPanel · self-hosted instance
Workflow Steps
1
Receive Reservation
Webhook node listens for POST requests sent by the React form. Extracts name, email, date, time, guest count, and optional notes.
2
Validate & Format
Code node validates all required fields, generates a unique reservation ID (RES-2026-XXXXX), formats date to Spanish locale, and sets initial status to pending.
3
Data Valid? (IF Branch)
IF node routes to the success path when all fields pass validation; routes to the error path otherwise, returning HTTP 400 with a list of invalid fields to the frontend.
4
Save to Google Sheets
Appends a new row with all reservation fields to a shared Google Sheet that serves as the restaurant's live CRM. Requires Google Sheets OAuth2 credential.
5
Email Confirmation to Client
Sends a branded HTML email to the guest confirming their reservation details — ID, date, time, guest count, and any special notes. Requires Gmail OAuth2.
6
WhatsApp Alert to Restaurant
Instantly notifies the restaurant owner via WhatsApp with the full reservation summary. Requires Twilio Basic Auth integration.
7
Success Response
Returns HTTP 200 with the confirmed reservation data to the React frontend. The UI displays a confirmation screen with the reservation ID to the client.

Key Features Delivered
  • Real-time webhook ingestion from React form
  • Server-side field validation with error feedback
  • Unique reservation ID generation (RES-2026-XXXXX)
  • Automatic Google Sheets row append (CRM)
  • Branded HTML email confirmation to guest
  • Instant WhatsApp alert to restaurant owner
  • HTTP 200 / 400 structured JSON responses
  • Clean IF/ELSE error branching logic
  • Self-hosted, no vendor lock-in
Architecture Decisions
  • n8n chosen for visual debugging & rapid iteration
  • Self-hosted to avoid per-execution pricing at scale
  • Google Sheets as CRM to match client's existing workflow
  • Validation in Code node for full JS flexibility
  • WhatsApp over SMS — client already used WhatsApp
  • Webhook returns response before email/WA send for speed
  • OAuth2 for all Google services — no hardcoded credentials
  • Modular nodes — easy to add SMS, Slack, or CRM later
